# 🎱 Equb Draw Bot

A WhatsApp bot that randomly assigns lottery numbers to all members of a group.

## How it works

1. Someone types `/draw` in the group
2. The bot fetches all group members
3. Shuffles them using a fair random algorithm (Fisher-Yates)
4. Posts the numbered results back to the group

---

## Setup & Installation

### Prerequisites
- Node.js v18 or higher → https://nodejs.org
- Google Chrome or Chromium installed on your machine (used by the bot internally)

### 1. Install dependencies

```bash
npm install
```

### 2. Run the bot

```bash
npm start
```

### 3. Scan the QR code

A QR code will appear in your terminal. Open WhatsApp on your phone:

> **Settings → Linked Devices → Link a Device**

Scan the QR code. The bot is now logged in as your WhatsApp account.

> ⚠️ The bot runs as YOUR WhatsApp number. Use a dedicated/secondary number for the bot.

### 4. Add to a group

Add your bot's number to any WhatsApp group. Then type `/draw` in the group.

---

## Commands

| Command | Description |
|---------|-------------|
| `/draw` | Runs the lottery — shuffles all members and assigns numbers 1 to N |
| `/help` | Shows available commands |

## Session persistence

The bot uses `LocalAuth` — after the first QR scan, the session is saved in a `.wwebjs_auth/` folder. You won't need to scan the QR again unless you log out.

---

## Running 24/7 (optional)

Install `pm2` to keep the bot alive in the background:

```bash
npm install -g pm2
pm2 start index.js --name equb-bot
pm2 save
pm2 startup   # auto-start on system reboot
```

---

## Troubleshooting

**QR code not showing** → Make sure you have Chrome/Chromium installed.

**Bot not responding** → Ensure the bot's number is in the group and has permission to send messages.

**Names showing as numbers** → The contact isn't saved in the bot's phone's contacts. The bot will fall back to showing the phone number instead.
